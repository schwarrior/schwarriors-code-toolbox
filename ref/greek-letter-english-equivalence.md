Greek Letter English Equivance
==============================

| Greek Letter | Name    | English Equivalent       |
| :----------- | :------ | :----------------------  |
| **Α α**      | Alpha   | **a**                    |
| **Β β**      | Beta    | **b** (modern: **v**)    |
| **Γ γ**      | Gamma   | **g** (hard)             |
| **Δ δ**      | Delta   | **d**                    |
| **Ε ε**      | Epsilon | **e** (short)            |
| **Ζ ζ**      | Zeta    | **z**                    |
| **Η η**      | Eta     | **e** (long/ee)          |
| **Θ θ**      | Theta   | **th** (as in *think*)   |
| **Ι ι**      | Iota    | **i**                    |
| **Κ κ**      | Kappa   | **k**                    |
| **Λ λ**      | Lambda  | **l**                    |
| **Μ μ**      | Mu      | **m**                    |
| **Ν ν**      | Nu      | **n**                    |
| **Ξ ξ**      | Xi      | **x**                    |
| **Ο ο**      | Omicron | **o**                    |
| **Π π**      | Pi      | **p**                    |
| **Ρ ρ**      | Rho     | **r**                    |
| **Σ σ/ς**    | Sigma   | **s**                    |
| **Τ τ**      | Tau     | **t**                    |
| **Υ υ**      | Upsilon | **u** (or **y**/**i**)   |
| **Φ φ**      | Phi     | **ph** (as in *photo*)   |
| **Χ χ**      | Chi     | **ch** (as in *loch*)    |
| **Ψ ψ**      | Psi     | **ps**                   |
| **Ω ω**      | Omega   | **o** (long)             |
