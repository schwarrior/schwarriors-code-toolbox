Visual Studio Keyboard Shortcuts
================================

# Toggle All Outlining
Ctrl + M, Ctrl + L

# Toggle Line Comment
Ctrl + /

# Toggle Block Comment
Ctrl + Shift + /

# Comment Section
Ctrl + K, Ctrl + C

# Uncomment Section
Ctrl + K, Ctrl + U

# Word Wrap
Ctrl + E, Ctrl + W

# View White Space
Ctrl + R, Ctrl + W

# Clipboard History
Ctrl + Shift + V

# Navigate Backward
Ctrl + -

# Navigate Forward
Ctrl + Shift + -
